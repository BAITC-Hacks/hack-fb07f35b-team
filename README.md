# FAQ-бот для репетиции хакатона (`hack-fb07f35b-team`)

Консольный чат-бот на чистом Python, который отвечает на 5 ключевых вопросов о репетиции хакатона (время, команда, трек, сдача, призы).

Проект не требует внешних библиотек (RAG и сторонние фреймворки не используются) — поиск реализован на базе анализа ключевых слов и стемминга из стандартной библиотеки Python.

---

## 📁 Структура проекта

```text
├── faq.txt       # База знаний: 5 пар вопрос-ответ по репетиции
├── bot.py        # Исходный код бота и логика поиска
├── test_bot.py   # Автотесты (unittest)
└── README.md     # Описание и руководство по запуску
```

---

## 🚀 Как запустить

### Требования
- Установленный Python 3.10 или выше (протестировано на Python 3.14).
- Сторонние зависимости **не требуются** (чистый Python).

### 1. Интерактивный режим чата
Запустите бота в терминале:
```bash
python bot.py
```
Вводите вопросы в свободной форме. Для выхода напишите `выход` или `exit`.

### 2. Одиночный запрос через аргументы
Можно передать вопрос сразу при вызове:
```bash
python bot.py "Во сколько начинается репетиция?"
python bot.py "Какие призы получат победители?"
```

### 3. Запуск тестов
```bash
python -m unittest test_bot.py
```

## 🧠 Как устроен поиск

1. **Загрузка FAQ**: Бот считывает пары `Q:` и `A:` из [faq.txt](faq.txt).
2. **Токенизация и очистка**: Запрос пользователя очищается от знаков препинания и стоп-слов («в», «на», «как», «что» и др.).
3. **Русский стемминг**: От слов отсекаются грамматические окончания (падежи, числа, спряжения).
4. **Скоринг совпадений**:
   - Подсчитывается пересечение корней слов запроса с корнями вопроса из FAQ.
   - Учитываются тематические ключевые кластеры для 5 тем (`врем`/`расписан`, `команд`/`состав`, `трек`/`прототип`, `сдач`/`дедлайн`/`гит`, `приз`/`мерч`/`наград`).
5. **Порог схожести**: Если набрано достаточное количество баллов, бот выдаёт ответ. Если уверенности нет (вопрос не по теме или пустой), бот честно отвечает: *«К сожалению, я не знаю ответа на этот вопрос»*.

Бот: До встречи и удачи на репетиции! 👋
